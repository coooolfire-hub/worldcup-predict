# 腾讯云轻量服务器部署教程（IP+端口，免备案）

这套是 Node.js + SQLite 版本，跑在你的腾讯云大陆服务器上，用 `http://你的IP:8080` 访问，国内能直接打开，不需要备案（因为不绑域名）。

---

## 前置：你需要准备

- 腾讯云轻量服务器（大陆地域，Ubuntu）—— 你已有
- 服务器的公网 IP（腾讯云控制台能看到）
- 一个能连服务器的工具：用腾讯云控制台自带的「网页终端」最简单，或用 SSH 工具（如 Windows 的 PowerShell / PuTTY）

---

## 第 1 步：开放 8080 端口（重要，否则外网访问不了）

1. 登录腾讯云控制台 → 轻量应用服务器 → 点你的服务器
2. 找到「防火墙」标签
3. 添加规则：协议 **TCP**，端口 **8080**，来源 **0.0.0.0/0**（所有）
4. 保存

> 不开这一步，浏览器访问 `http://IP:8080` 会一直转圈连不上。

---

## 第 2 步：连上服务器，装 Node.js

用腾讯云控制台的「登录」按钮进网页终端（或 SSH 连上），然后执行：

```bash
# 装 Node.js 20（Ubuntu）
curl -fsSL https://deb.nodesource.com/setup_20.x | sudo -E bash -
sudo apt-get install -y nodejs

# 验证
node -v    # 应显示 v20.x.x
npm -v
```

如果 `curl` 那条因为网络慢失败，多试两次，或换用 apt 自带的：
```bash
sudo apt update && sudo apt install -y nodejs npm
```
（apt 自带的版本可能旧一点，但 18+ 都能跑。）

---

## 第 3 步：上传项目代码到服务器

**方法 A：用 git（推荐，你代码已经在 GitHub）**

```bash
cd ~
git clone https://github.com/coooolfire-hub/worldcup-predict.git
cd worldcup-predict
```

> 如果你的 GitHub 仓库已经更新到最新（包含 server/ 目录），直接 clone 就有了。如果没有，先在本地把这次的 server/ 目录 push 上去。

**方法 B：用腾讯云的文件上传**

把项目文件夹打包成 zip，通过控制台或 scp 传上去，解压。

---

## 第 4 步：安装依赖

```bash
cd ~/worldcup-predict/server
npm install
```

这一步会装 `better-sqlite3`，它需要编译（服务器上能正常编译，不像某些受限环境）。如果报错缺编译工具，先装：
```bash
sudo apt-get install -y build-essential python3
```
然后再 `npm install`。

> 备注：如果 better-sqlite3 死活装不上，代码会自动回退用 Node 内置的 sqlite（需要 Node 22+）。装 Node 22 的话改第2步的 `setup_20.x` 为 `setup_22.x`。

---

## 第 5 步：初始化数据库

```bash
cd ~/worldcup-predict/server
node init-db.js
```

成功会显示「✓ 已执行 schema.sql」等几行，生成一个 `worldcup.db` 文件。

---

## 第 6 步：设置密钥并启动

```bash
# 设置 api-football 的 key 和管理员 token（换成你自己的值）
export SPORTS_API_KEY="你的apifootball的key"
export ADMIN_TOKEN="你自己设的管理员密码"

# 启动
node server.js
```

看到「先知局服务已启动: http://0.0.0.0:8080」就成功了。

**现在浏览器打开 `http://你的服务器IP:8080`**，应该能看到网站，国内直接可访问！

---

## 第 7 步：录入比赛数据

服务器跑起来后，在浏览器开发者工具 Console 里执行（或用 curl）：

```javascript
fetch('http://你的IP:8080/api/admin/seed-test-matches', {
  method: 'POST',
  headers: { 'Authorization': 'Bearer 你的ADMIN_TOKEN' }
}).then(r => r.json()).then(d => console.log(JSON.stringify(d)))
```

返回「已录入 18 场真实赛程」就好了。

---

## 第 8 步：让服务后台常驻（关掉终端也不停）

上面 `node server.js` 一关终端就停了。用 pm2 让它常驻：

```bash
# 装 pm2
sudo npm install -g pm2

# 用 pm2 启动（先设好环境变量）
cd ~/worldcup-predict/server
SPORTS_API_KEY="你的key" ADMIN_TOKEN="你的token" pm2 start server.js --name worldcup

# 设置开机自启
pm2 startup
pm2 save
```

之后服务会一直在后台跑，重启服务器也会自动拉起。

常用 pm2 命令：
```bash
pm2 list          # 看运行状态
pm2 logs worldcup # 看日志
pm2 restart worldcup  # 重启
pm2 stop worldcup     # 停止
```

---

## 日常维护

**更新代码**（你在本地改完 push 到 GitHub 后）：
```bash
cd ~/worldcup-predict
git pull
cd server
npm install   # 如果加了新依赖
pm2 restart worldcup
```

**重新录入比赛**：重新调一次第 7 步的 seed 接口。

---

## 重要说明

1. **这是 IP+端口访问，没有 HTTPS**，浏览器地址栏会显示「不安全」，内测无所谓。
2. **不绑域名 = 不需要备案**，合规。等以后要正式对外、要域名和 HTTPS，再走备案。
3. **前端里的后端地址**：`server/../worker/frontend-html.js` 里前端的 `API_BASE` 现在指向旧的 workers.dev。部署到服务器后，因为前后端同源（都在 `IP:8080`），需要把前端的 API_BASE 改成空字符串（相对路径）或你的 `http://IP:8080`。这个我已经在代码里处理——如果没处理，告诉我，我改一下。
4. **数据库就是 server 目录下的 worldcup.db 文件**，备份它就等于备份所有数据。
